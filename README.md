# JavaScript — Estudos e Fundamentos

Repositório de **estudo de JavaScript** que preserva exercícios e exemplos produzidos durante a aprendizagem da linguagem.

> Este é um repositório educacional. Ele registra evolução técnica e não é apresentado como projeto autoral de produção.

## Conteúdo

Os diretórios estão organizados por assunto e incluem, entre outros:

- tipos de dados e operadores;
- estruturas de programação;
- funções;
- arrays e objetos;
- orientação a objetos;
- DOM;
- eventos;
- programação assíncrona;
- expressões regulares;
- debugging.

## Objetivo

O repositório serve como registro dos fundamentos necessários para trabalhar com JavaScript no navegador e compreender melhor a camada frontend de aplicações web.

Para avaliação de engenharia de software e projetos autorais, consulte os projetos destacados no perfil principal do GitHub.

## Organização

Cada diretório representa um tópico de estudo independente. Os exemplos podem ser executados conforme a necessidade diretamente no navegador ou com um ambiente JavaScript compatível, dependendo do conteúdo.

## Princípios de manutenção

- preservar o histórico de aprendizagem;
- identificar claramente conteúdo de estudo;
- não adicionar commits apenas para gerar atividade;
- manter exemplos legíveis e pequenos;
- não versionar segredos, dependências geradas ou arquivos locais desnecessários.
